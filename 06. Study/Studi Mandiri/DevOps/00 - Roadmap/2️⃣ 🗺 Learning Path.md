# DevOps Learning Path

Target Durasi: 6 Bulan  
Goal Akhir: Deploy & manage production-ready app dengan CI/CD + Docker + Cloud

---

# 🔹 Phase 1 – Foundation (Month 1)

## Fokus:
- Linux Deep Dive
- Git Advanced
- Networking Basics

## Materi:
- File system & permission
- Process & service management
- SSH & firewall
- Git branching & workflow
- HTTP, DNS, Port

## Output Project:
- Setup VPS manual
- Deploy static app via Nginx
- Git workflow clean & terstruktur

## Skill Target:
- Linux → Intermediate
- Git → Intermediate
- Networking → Basic solid

---

# 🔹 Phase 2 – Containerization (Month 2)

## Fokus:
- Docker
- Docker Compose

## Materi:
- Dockerfile
- Multi-stage build
- Volume & network
- Compose multi-service

## Output Project:
- Dockerize Next.js app
- Run app + database via Docker Compose

## Skill Target:
- Docker → Intermediate

---
# 🔹 Phase 3 – CI/CD Automation (Month 3)

## Fokus:
- GitHub Actions
- Pipeline concept

## Materi:
- Workflow YAML
- Trigger event
- Build & deploy automation

## Output Project:
- Auto build Docker image
- Auto deploy ke VPS tiap push

## Skill Target:
- CI/CD → Intermediate

---
# 🔹 Phase 4 – Cloud Infrastructure (Month 4)

## Fokus:
- Cloud provider (pilih satu)
- VM & networking cloud

## Materi:
- Compute instance
- Storage
- Security group
- IAM basic

## Output Project:
- Deploy app ke cloud VM
- Setup domain + HTTPS

## Skill Target:
- Cloud → Basic solid

---
# 🔹 Phase 5 – Infrastructure as Code (Month 5)

## Fokus:
- Terraform

## Materi:
- Provider
- Resource
- State
- Variable

## Output Project:
- Provision VM via Terraform
- Auto setup infra

## Skill Target:
- IaC → Intermediate

---
# 🔹 Phase 6 – Kubernetes Intro (Month 6)

## Fokus:
- Kubernetes fundamentals

## Materi:
- Pod
- Deployment
- Service
- Ingress
- ConfigMap

## Output Project:
- Deploy containerized app ke local k8s (kind/minikube)

## Skill Target:
- Kubernetes → Basic understanding
